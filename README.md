# Rekordbox BPM Metadata Manager
A Windows desktop app & CLI tool for Rekordbox. Extracts analyzed BPM & Key metadata, converts keys to Camelot (8A/12B) or OpenKey, writes ID3/Vorbis/MP4 tags, and batch renames audio files with customizable templates. Automatically synchronizes Rekordbox master.db paths to prevent missing files, with full 1-click revert support.
